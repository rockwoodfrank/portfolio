Using a multi-step pipeline, the codebase that we developed 
detects target objects with a stationary camera and OpenCV 
processing, matrix translation developed with the Denavit Hartenburg convention, 
velocity-based trajectory planning, and a custom PID controller. The result is a controller 
for the 4 degree-of-freedom OpenManipulatorX robotic arm that allows for identification and manipulation 
of real world objects.
